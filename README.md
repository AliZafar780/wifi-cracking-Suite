## ✨ Features

### 🔍 Network Discovery & Scanning
- **Advanced Network Scanner** — Comprehensive wireless discovery
- **Multi-platform Support** — Linux, Windows compatibility
- **Real-time Monitoring** — Live network statistics
- **Network Filtering** — By encryption, signal strength, WPS
- **Vendor Identification** — MAC to vendor lookup
- **Channel Analysis** — Channel utilization detection

### 📡 Packet Capture & Analysis
- **Multi-format Capture** — pcap, pcapng support
- **Advanced Packet Analysis** — Deep inspection
- **Protocol Decoding** — WPA/WPA2/WPA3, WPS, EAPOL
- **Handshake Extraction** — Automated WPA handshake capture
- **PMKID Detection** — Advanced PMKID attack support

### 🔐 Authentication Cracking
- **Dictionary Attacks** — High-performance wordlist cracking
- **Rainbow Tables** — Pre-computed hash lookup
- **GPU Acceleration** — CUDA/OpenCL support

## 🚀 Quick Start

```bash
# Clone the repository
git clone https://github.com/AliZafar780/wifi-cracking-Suite.git
cd wifi-cracking-Suite

# Install dependencies
pip install -r requirements.txt

# Run the tool
sudo python wifi_suite.py
```

> ⚠️ Requires root/administrator privileges for network operations

## 📋 Requirements

- Python 3.8+
- Linux or Windows
- Wireless adapter in monitor mode
- See requirements.txt for dependencies
